## Notable finding (documented in the PRD)
Reading `card_recommendation.py` against owner Decision #1 ("total first-year value =
ongoing rewards + sign-up bonus"), the engine is **half-implemented**:
- `recommend_next_card` scores `bonus − fee + credits` and **omits ongoing rewards**;
  `profile.category_breakdown` (the dining-habits signal that is the product's premise) is
  **unused**. `analyze_portfolio` uses only flat `universalCashbackPercent`.
- Sign-up bonuses are summed as raw point `amount`s with **no cents-per-point valuation**,
  so bonus "value" is in points and not comparable to cashback dollars — rankings are
  currently apples-to-oranges.
The consumed card dataset also exposes only a flat cashback rate (no per-category
multipliers), so true category-aware earn needs upstream enrichment or a flat-rate v1.
