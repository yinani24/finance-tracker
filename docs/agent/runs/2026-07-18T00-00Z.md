## Why this slice (product value, not just UX)
The rec engine matches **held** cards to the public dataset by
`_card_key = f"{name.lower()}|{issuer.upper()}"` (`app/services/card_recommendation.py:41`);
`analyze_portfolio` uses that match to value each wallet card. The freeform manual
add form has no `issuer` field, so manually-typed cards rarely match the dataset and
the engine can't value them. Adding straight from the catalog stores `name`+`issuer`
verbatim, so the held card matches its catalog entry and the portfolio analysis works.
This directly improves recommendation quality — the core MVP loop (PRODUCT.md step 3).
