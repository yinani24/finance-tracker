## What I advanced — Stage 1 (#55) + Stage 4 (PR for #55)
**Found: `recommend_next_card` drops multi-tier cards whose top offer is unachievable.**
- `card_recommendation.py:_best_offer` returns each card's single **highest-dollar-value** offer; achievability (`months_to_hit ≤ days/30`) was checked **only against that one offer**. So a card whose top tier is out of reach was dropped entirely — even when a smaller tier was achievable.
- **Verified against the live dataset** (`credit-card-bonuses-api/exports/data.json`, master): offer-count distribution `{0:13, 1:139, 2:27}` → **27 of 179 cards (15%) carry two concurrent offers**, always a high-spend/high-bonus tier + a low-spend/low-bonus tier (e.g. Delta SkyMiles Gold 90k @ $5,000/180d **or** 50k @ $2,000/180d; Delta Platinum, Hilton Honors, etc.).
- **Impact:** a $400/mo user can't hit Delta Gold's $5k/180d top tier (12.5 > 6 months) but *can* hit the $2k/180d smaller tier (5 ≤ 6) — yet the engine showed them nothing. The bug disproportionately penalizes the lower-spend users the achievability filter exists to protect.

**Implemented #55** on `agent/55-best-achievable-offer` → PR (`Closes #55`):
- Replaced `_best_offer` with `_best_achievable_offer(card, avg_monthly_spend, points_value_cents)` → `(offer, months_to_hit) | None`: filters a card's offers to the achievable tiers, then takes the highest USD-valued one (all other score terms are per-card constants, so bonus value is the sole differentiator). Card skipped only when *no* tier is achievable.
- Hoisted the `avg_monthly_spend <= 0` guard to an early `return []` (equivalent to the old per-card `continue`, cleaner).
- Tests: 3 new (`TestMultiTierOffers`) — smaller tier used when top unachievable; top tier wins when achievable; card dropped only when no tier reachable. All existing single-offer tests unchanged.
- Verified in-sandbox: `pytest tests/test_card_recommendation_service.py --noconftest` → **33 passed**; `ruff check card_recommendation.py` clean (the 3 pre-existing E501s in the test file exist on `origin/main` too, untouched); modules compile.
